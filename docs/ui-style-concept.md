# Now 时间线：UI 风格概念

## 1. 核心画面

时间线页面可以采用“粒子 / 光轨 / 时间空间”的视觉隐喻，但不限定为深色背景。

关键词：

- Light / Dark 双主题
- 微弱粒子场
- 可缩放时间线
- 可拖拽空间
- 时间点是光点
- 时间线是光柱 / 光轨
- 记录片段从光点延伸出来
- 信息卡片周围粒子自动消退，保证阅读区域干净

目标不是做炫酷背景，而是做一个有空间感、记忆点和沉淀感的时间系统。

---

## 2. 最大风险

粒子背景和文字内容天然冲突。

风险：

- 背景太亮，文字可读性下降
- 动效太多，页面疲劳
- 记录卡片太重，破坏光轨的轻盈感
- 纯文字太轻，被背景吞掉
- 缩放后信息层级混乱
- Light / Dark 两套主题如果后期才补，会导致颜色系统混乱

所以必须把视觉分层，并从一开始使用主题变量。

---

## 3. 主题策略

Now 时间线应该支持 Light / Dark 两套主题。

不要把深色当成唯一默认，也不要让浅色模式变成“深色模式反色版”。

### Dark Mode

气质：夜空、深海、宇宙、低亮光轨。

建议：

- 背景：深蓝黑 / 紫黑 / 近黑灰
- 粒子：低亮度冷色
- 光轨：蓝紫 / 青色 / 柔白
- 信息片：半透明深色玻璃
- 文字：高对比但不要纯白刺眼

### Light Mode

气质：天空、海面、白蓝高饱和对比、清亮光尘。

Light Mode 不必走低饱和雾灰路线，可以尝试更有记忆点的白蓝系统。

建议：

- 背景：接近白色的天空蓝 / 冰白 / 浅海蓝渐变
- 粒子：高饱和蓝、克莱因蓝倾向、少量白色光点
- 光轨：克莱因蓝 / 电光蓝 / 海水蓝
- 信息片：半透明白色玻璃或带轻微蓝调的雾面卡片
- 文字：深蓝灰，不用纯黑
- 强调色：克莱因蓝可以作为节点、光轨、按钮和焦点态使用

注意：克莱因蓝不适合大面积铺满背景，更适合作为高能强调色。背景应该保留足够白度，让它像天空和海的反光，而不是整页蓝色墙面。

Light Mode 的粒子可以比雾灰方案更鲜明，但必须避开文字阅读区。信息卡片周围的粒子消退在 Light Mode 下尤其重要。

---

## 4. 推荐视觉分层

### 背景层

- 根据主题切换浅色 / 深色底
- 慢速粒子
- 低透明度
- 不要高频闪烁
- 不要让粒子穿过文字高亮区域
- 信息卡片周围粒子自动降低透明度或避让

背景只提供氛围，不抢内容。

### 时间线层

- 主时间线可以是纵向或横向光柱
- 光柱亮度克制
- 当前视野中心附近稍亮
- 远处节点变暗
- 缩放时显示不同信息密度
- Light / Dark 下光柱颜色不同，但行为一致

### 节点层

时间点用光点表示。

节点状态：

- 默认：小光点
- hover / focus：光晕扩大
- 选中：光柱增强，记录片段展开
- 重要节点：可有轻微脉冲

### 内容层

记录内容不要直接裸文字漂在粒子背景上。

推荐用“轻量信息片”而不是传统厚卡片。

---

## 5. 信息卡片周围粒子消退

这是关键设计。

当信息片出现时，它周围应该形成一个轻微的“阅读净空区”。

效果：

- 卡片背后的粒子透明度降低
- 卡片附近的粒子密度降低
- 粒子不要穿过文字区域
- 卡片外缘可以保留少量流动感

视觉隐喻：

> 记录被阅读时，周围噪声退开。

实现上可以分阶段：

### MVP 实现

- 信息片本身使用半透明背景 + backdrop blur
- 卡片加一个柔和 radial-gradient mask / glow
- 卡片区域盖一层低透明度背景罩

### 进阶实现

- 粒子系统读取卡片 bounding box
- 卡片附近粒子降低 alpha
- 或对卡片区域做避让 / 排斥

先做 MVP 实现，不要一开始就把粒子系统写复杂。

---

## 6. 记录片段展示方案

### 方案 A：玻璃信息片

从时间光点延伸出一条细线，连接到半透明玻璃片。

特点：

- 可读性好
- 视觉上不算太重
- 容易做编辑 / 删除操作

样式建议：

- Light / Dark 两套玻璃变量
- 轻微 blur
- 细边框
- 低阴影
- 最大宽度限制
- 内容超过一定长度折叠

适合作为默认方案。

### 方案 B：悬浮文字 + hover 展开

默认只显示一行短文本，hover / 点击后展开详情。

特点：

- 画面轻
- 空间感强
- 适合大量节点

风险：

- 移动端 hover 不成立
- 编辑操作不方便
- 长文本不好处理

适合作为缩放远景 / 概览模式。

### 方案 C：节点聚焦详情面板

时间线上只显示光点和短标题。

点击节点后，右侧或底部出现详情面板。

特点：

- 时间线非常干净
- 阅读体验好
- 移动端可用 bottom sheet

风险：

- 节点和内容的空间连接感会弱一些

适合作为移动端或节点密集时的方案。

---

## 7. 推荐组合

不要三选一，应该分缩放层级使用。

### 远景模式

用户缩小时间线时：

- 只显示光点
- 显示日期 / 时间刻度
- 不显示完整内容
- 重要节点可显示短标题

### 中景模式

普通浏览状态：

- 显示光点
- 显示一行摘要
- 摘要用轻量文字条 / 小玻璃片

### 近景模式

用户放大或选中节点时：

- 展开完整玻璃信息片
- 显示完整内容
- 显示编辑 / 删除操作
- 光点和信息片之间有细线连接
- 信息片周围粒子消退，形成阅读净空区

这套逻辑可以解决“卡片太臃肿”和“纯文字不清楚”的矛盾。

---

## 8. 移动端处理

移动端不要强行做桌面式自由拖拽时间线。

建议：

- 时间线主体仍可纵向滚动
- 光点 + 光柱保留
- 点击节点后用 bottom sheet 展示记录详情
- 粒子背景进一步降低强度
- 输入和编辑放在底部弹层
- Light Mode 下默认降低粒子密度

移动端重点是清晰和快速记录，不是炫技。

---

## 9. 动效原则

动效应该像“沉淀”，不是“爆炸”。

建议：

- 新节点从光点轻轻亮起
- 记录片段从光点延伸出来
- 完成 Todo 转时间线时，光点生成
- 粒子被轻微吸附到节点附近
- 信息片淡入，而不是弹窗砸出来
- 信息片出现时，周围粒子缓慢退开

禁止：

- 大面积烟花
- 高频闪烁
- 过亮霓虹
- 影响文字阅读的背景运动

---

## 10. 当前建议

默认采用：

> Light / Dark 双主题 + 粒子背景 + 光柱时间线 + 光点节点 + 近景玻璃信息片 + 信息片周围粒子消退 + 远景摘要模式。
> Light Mode 优先尝试天空 / 海 / 白蓝高饱和方向，克莱因蓝作为强调色。

一句话：

> 背景负责氛围，光点负责时间，玻璃信息片负责阅读，粒子在阅读发生时退开。

不要让粒子和文字抢同一个视觉层级。
